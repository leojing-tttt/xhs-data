# 小红书搜索导出

在小红书 PC 搜索结果页，把**当前已经加载出来的笔记**导出成 Excel。

示例页：`https://www.xiaohongshu.com/search_result?keyword=大平层装修&source=web_user_page`

## 怎么加载

Chrome 或 Edge：

1. 打开扩展管理页：Chrome 用 `chrome://extensions`，Edge 用 `edge://extensions`。
2. 打开「开发者模式」。
3. 选择「加载已解压的扩展程序」，指向本目录 `extensions/xhs-search-export/`。
4. 更新过扩展文件后，在扩展管理页对「小红书搜索导出」点一次「重新加载」。已经打开的小红书标签会重新挂上按钮；如果仍没有，再刷新那个搜索页。
5. 打开搜索结果页，或在首页搜完跳进搜索。页面右下角会显示已捕获条数。向下浏览，列表继续加载时条数会增加。点「导出 Excel」，或点扩展图标里的同一个按钮。

## 导出什么

一个 `.xlsx`，文件名形如 `小红书搜索_大平层装修_20261104-0356.xlsx`。关键词来自页面地址里的 `keyword`，时间是导出时的本地时间。

一行一条笔记。表头按数据里实际有的字段保留，顺序是：

笔记ID、标题、作者、作者ID、点赞数、笔记类型、封面图、笔记链接

标题、作者、笔记链接始终保留。某一列在已捕获的数据里从未出现时，这一列不写。笔记类型里，`normal` 写成「图文」，`video` 写成「视频」。笔记链接是 `https://www.xiaohongshu.com/explore/{笔记ID}`；接口若带了页面自己的 `xsec_token`，链接会带上它。

## 数据从哪来

优先读取搜索页自己已经发出的搜索接口响应（`search/notes`），按笔记 ID 去重后累加。不另外请求小红书，不用伪造 Cookie，也不处理登录、验证码或频率限制。

接口结构对不上时，才退回到当前能看见的笔记卡片。这种回退只能看到当时还留在页面上的卡片。

换了一个新的关键词之后，之前捕获的笔记会清掉，避免串到新的文件里。搜索页地址如果暂时丢掉 `keyword`（例如点开一条笔记），已捕获的笔记还留着。

还没有捕获到笔记时，按钮会说明原因，不会下载一个看起来像空表的文件。

## 不做什么

- 不导出评论、用户主页，也不批量爬账号。
- 不自动滚动，不去打站点的接口。
- 不导出你还没在当前搜索结果里加载出来的笔记。
- 搜索接口若改了地址或字段，可能暂时只能走到可见卡片，字段会少一些。

Excel 使用随扩展带上的 SheetJS Community `0.18.5`（Apache-2.0，见 `vendor/xlsx.LICENSE`），不从远程 CDN 加载脚本。
